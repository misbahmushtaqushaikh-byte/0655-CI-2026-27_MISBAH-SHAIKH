# Swiggy Order Data Analysis

A small exploratory data analysis project using Python, pandas, and Matplotlib. The notebook inspects Swiggy-style order data, checks missing values, groups data by product and region, and creates charts for order trends, prices, ratings, and city distribution.

## Files

- `milestone.ipynb` — analysis notebook
- `swiggy.csv` — dataset (30 orders, October 1–15, 2026)

Keep both files in the same folder so the notebook can load the CSV.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- pandas
- matplotlib

Install dependencies:

```bash
python -m pip install pandas matplotlib jupyter
```

## Run

Start Jupyter in the project folder:

```bash
jupyter notebook
```

Open `milestone.ipynb` and run the cells from top to bottom.

## Note

The dataset contains missing values. The notebook demonstrates basic inspection and handling; its charts and results are exploratory.
